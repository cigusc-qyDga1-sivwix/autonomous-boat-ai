# BOAT LAB v1.1 — 全国開催の自動取得・締切前予想 PWA

GitHub Pages: https://cigusc-qydga1-sivwix.github.io/autonomous-boat-ai/

## 自動で動く機能

- GitHub Actions がJST約06:00〜23:59の間、10分間隔で実行予定。
- 1日分の非公式 Boatrace Open API v1 を取得し、全国24場のうち当日開催している場（最大288R）を収集。
- 発走前に6艇分の出走表が揃えば「展示前暫定予想」を1回固定。
- 締切前に6艇分の展示ST・展示タイム・進入と場内風速・波高が揃った場合だけ「展示反映予想」を1回追加固定。
- 予想はPlackett–Luceに基づく未訓練・未校正の試験用ヒューリスティック。勝率・モーター2連対率・平均ST・コース、展示の簡易重みを使用。気象は記録と表示のみで、学習済み水面補正ではない。
- 3連単8点・合計50,000円の仮想金額。オッズでの採算判断は未実施。
- 予想時刻・SHA256・2段階のスナップショットを日付別JSONおよびGitコミットに保存。結果データは予想計算に渡さない。締切後は新規予想を作らない。
- 非公式結果・3連単払戻が出たら、既に発走前固定されたレースのみ照合。結果から後出しで買い目を追加しない。
- iPhoneは起動時と画面復帰時に最新を取得。アプリを開いている間は5分間隔で確認。通知・自動購入なし。

## ファイル構成

- .github/workflows/boat-lab-auto.yml — 定期収集・保存・公開。
- scripts/autonomous_daily.py — 全国取得と締切前固定・結果照合。
- app/data/live/YYYY-MM-DD.json — 日付別・レース別の固定記録と結果。
- app/data/live/latest.json — PWAが読む集約データ。
- .github/workflows/boat-lab-pages.yml — アプリの通常公開。
- tests/test_autonomous_daily.py — 締切後の後出し防止の自動テスト。

GitHub Actionsのcronには実行遅延があり、毎レースの締切10分前を保証しません。非公式APIも数分遅延や欠損があり、間に合わない場合は「未固定」として後出ししません。開催のない日や障害では昨日のデータが残ることがあります。画面の対象日と最終更新時刻を確認してください。

## iPhoneで更新を見る

ホーム画面のBOAT LABを開くと新しい予想データを自動読込。手動更新は右上の↻。手動インポートしたデータが優先される場合は「データ管理 → 元の予想に戻す」で自動配信に戻ります。
