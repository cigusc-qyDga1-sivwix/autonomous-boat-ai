# 全国24場の実験的な会場ロジック v0.1

2026-10-23。正式収支用の発走前スナップショットとは区別して試験導入。

## 実装した範囲
- `scripts/venue_profiles.py` の24場ごとに `水質／風の注意度／潮流・水位の監視対象／水面・進入の特徴／注目する攻防／独立集計の参考1コース1着率` を保持。
- `scripts/autonomous_daily.py` の発走前予測のスコアへ、**実進入1コース**の弱い相対補正だけを適用する。
  - 参考1コース1着率を `r` として `exp(clamp(0.6 * (r - 0.55), -0.10, 0.10))` を当該艇の相対評価に掛ける。
  - 例：戸田 r=.429 → 約×0.930、徳山 r=.632 → 約×1.050、唐津 r=.557 → 約×1.004。
  - あくまで未校正の弱い参考値。**勝率＝1号艇の実際の的中確率ではない**。
- 展示で進入コースが変わった場合、枠番1ではなく、**実進入1コース艇**に係数を適用。重複・不完全進入なら新たな補正なし。
- 全場で既存の発走前の風・波の入力と選手・モーター・展示能力の評価を維持。風の方向を観測せず「唐津だから向かい風」と決めつけることは禁止。
- 潮流に影響される会場でも**潮位・流速・流向の実測/予報はまだ接続されていない**。現時点で潮の大小による艇ごとの係数は適用しない。
- `app/venue-profiles.html` は24場の設定を閲覧できるページ。新しく固定するレースには会場名・考慮する戦法・相対補正・不足している情報が表示される。
- 既存の展示前・展示後の発走前固定記録と検証用収支は上書きしない。実際の予想効果は未評価。
- 予想ロジックはまだ艇間の差し場・抵抗・ターン出口・バックの着順連動を数理シミュレーションしていない。場ごとの戦法説明は**検証すべき仮説**。

## 唐津固有の注意点
- 公式：[水面特性・進入コース別情報](https://www.boatrace-karatsu.jp/modules/datafile/?page=index_suimen)
- 淡水、水位変化・水の流れは通常なし、比較的広い競走水面。
- 朝は向かい風、午後に追い風へ変わる傾向があるが、実際のレースは**取得できた現場の風**で判断。
- **2025年12月からピット位置変更、ピットから2マーク173m**。進入深度とピット離れを仮説として観察する。
- 1先マイ、2差し、3まくり差し、4カド攻めと内側艇の残存を複数分岐で検討。決め手は能力・実進入・実際の風・モーター調整・戦法適性。

## 24場の参照元と品質
- 過去の1コース参考率：[KOUEI-LAB 24場比較](https://kouei-lab.com/venues.html)。参照した一覧では対象集計期間と進入記録率の根拠が十分示されておらず、校正済み勝率にはできない。
- 他の会場別要点は水面に関する広く知られた傾向を初期仮説として登録。**場によって事実の信頼性に差があり、独立した検証が必要。**
- 改善工程：
  1. 公式ソースによる各場のコース別成績と決まり手・統計期間・サンプル数の再取得
  2. コース内の選手能力・機力と、モーター調整後の展示推移を組み合わせた因果仮説
  3. 各場の実測風向・風速と潮位等を入力し、向かい風/追い風・潮の効果を会場単位で推定
  4. 1号艇先マイ、2差し、3まくり差し、4カド攻めといった対抗シナリオを艇間連動に接続
  5. 最低100R目安の同一レース・事前固定A/Bで頭捕捉、2・3着残存、的中率、回収率を検証

## アニメーションの表示枠の改善
- **枠＝再生映像の表示領域**。表示領域を16:9に変更し、スマホでも水面の動きが見やすい高さを確保。
- レース実映像の取り込み・追跡・物理衝突判定の実装ではない。
- 本稿と設定は試験段階。予測精度や実投票の成功は保証されない。
