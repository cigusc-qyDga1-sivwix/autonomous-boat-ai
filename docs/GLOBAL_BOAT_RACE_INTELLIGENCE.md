# BOAT LAB：全国24場の情報収集マスタープラン（2026-10-23）

## 方針

「出走表 → 実進入・展示 → スタート → 1マーク → バックストレッチ → 着順・決まり手」を、同一レースの12桁キーで追跡し、説明可能な予想を構築する。配分は仮想5万円、3連単4〜12点の試験枠。データ収集量と的中率の向上は別物。

## 新しく接続した6種類の情報源

| ソース | 収録内容 | 特徴量の仮説 |
| --- | --- | --- |
| Race Cards | 全国・当地成績、F/L、モーター・ボート、節内14走 | 素の能力・今節調子 |
| Waku10 | 今回の枠番での直近10走、枠別ST | 枠ごとのスタート・コース取り |
| Recent National | 全国直近5節・格・着順列 | 短期調子、格の補正 |
| Recent Local | 当地直近5節 | 場への適性 |
| Motor Stats | モーター2/3連対率、ラップ秒、整備回数・日付 | 以前の能力と整備変化 |
| Motor History | 過去節使用者と成績（直前3日分の節終了キーから探索） | 選手の腕に依存するモーター成績の識別 |
| Title | レース名称・格・節日数 | 準優・優勝戦・予選の違い |

実装：scripts/ingest_global_intelligence.py
出力：app/data/intelligence/YYYY-MM-DD.json と status-latest.json
閲覧：app/intelligence.html
収集：GitHub Actions の専用ワークフロー（JST 06:20 / 14:20 と手動実行）。
各取得元にURL、HTTP取得日時、CSV行数、SHA256、失敗理由を保存。共通キーは YYYYMMDDjjrr、モーターの連結キーは場コード＋モーター番号。
CSV由来の独立収集は情報の完全性を保証しない。非開催場は当然欠損する。

## 既に収集しているものとの結合

- 展示（BoatraceCSV stt / tkz / sui / original_exhibition）：進入、展示ST、展示タイム、チルト、周回/回り足/直線、風・波。江戸川は原則オリジナル展示配信がないため欠損=故障ではない。
- BOATRACE OpenAPI：本番の出走表・当日データ。独立集計元との不一致はフラグにする。
- 準リアルタイム結果・オッズ：研究用。確定結果の正本はBOATRACE公式払戻との独立照合。オッズは集計中の値で、締切時点の確定オッズではない。
- 公式BOATRACE：レーサー期別成績、競走成績、番組表、24場データ。LZHなどの変換が必要なためこの変更では自動ダウンロードしない。
- 気象庁：過去風向風速、潮位予測、実測潮位等を公開。外海の潮位・近隣観測点の風を競走場の実測と混同しない。アクセス頻度と利用規約に注意。

## 進める解析と優先順位

1. **モーター能力と整備**：モーター期別率だけでなく、同一機を使った過去選手の強さ、使用開始日、整備日、前走からの展示・回り足推移を調査。整備の種類そのものが足改善の証拠とは限らない。
2. **実進入とスタート**：枠別直近10走、展示進入、F/L、スタート勘、風で条件付き評価。枠番1=1コースと固定しない。
3. **戦法**：逃げ・差し・まくり・まくり差し・競り合い・抵抗を別分岐として評価。実際の決まり手だけではバックの全艇位置や攻防が分からないため、映像は取得条件・利用許諾が確保できれば別途アノテーションする。
4. **2・3着残存**：1着戦法ごとに、2着浮上・3着残りの条件付き確率を測る。確率は時系列に校正し、100〜300R程度の事前固定で旧モデルと比較する（評価サンプル数は後から拡張）。
5. **採算性**：未確定オッズと最終払戻を区別し、4〜12点の仮想配分と条件付き的中率・回収率を分離評価する。

## 最重要の情報漏洩防止

- 過去のCSVを今日ダウンロードしても、それが過去のレースの**締切前に自分たちが利用できた証拠にはならない**。新ファイルは研究用であり、予想エンジンに自動接続しない。
- レース後の確定着順/決まり手/払戻は評価ラベル。特徴量としてモデルに混ぜない。以前固定したSHA・買い目・正式収支は不変。
- 収集できない日、値、情報源の列は空欄または「未取得」とする。値0との区別を残す。
- 過去日のmotor_history.csvの日付は**基準節終了日**であって、当日レース日ではない。取得した行も使用終了日が対象日より前の場合のみ使用する。
- 同一選手・同一モーター・同一節に関連する学習サンプルは時系列に沿って評価し、学習からの結果漏洩を防ぐ。
- BOATERSその他の商用サイトは、利用条件が確認できるまで自動スクレイピングしない。

## 監査/実行

- python scripts/ingest_global_intelligence.py --date 2026-10-23 --history-days 3
- python -m pytest -q tests/test_global_intelligence.py
- 取得レース数、24場中開催場数、モーター紐付け率、登録番号欠損、取得失敗理由、各CSVの取得時刻を日次レポートで監視する。
- GitHubのcronは遅延/欠落の可能性があるため、実行成功・公表レコード数を検証してから「実際に収集できた」と報告する。
