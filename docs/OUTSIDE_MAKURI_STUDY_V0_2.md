# 外枠4・5・6号艇／まくり・まくり差し研究 v0.2（2026-10-23）

## 結論と証拠の分離
- 旧モデルの **course priors** は `[.48,.18,.16,.105,.05,.025]`。選手能力などで調整されるものの、特に5・6コースの頭への入り口が狭い。
- 2026-10-23 16:42頃の `app/data/live/audit-latest.json`：BOATRACE公式払戻で検証済み134Rの勝者は1号艇73R、4号艇13R、5号艇7R、6号艇2R。旧正式予想の筆頭買い目は168/168で1号艇から。**4〜6号艇計22/134R（16.4%）**。対象の時刻が異なるレース数を無理に統合しない。
- 別系統の `app/data/exhibition/2026-10-23.json`：非公式結果が存在する133Rのうち4〜6号艇の勝利23R。勝利決まり手の内訳：まくり8、まくり差し7、抜き4、差し2、恵まれ2。**過去結果を予想入力に混ぜず、事後の研究ラベルとしてのみ扱う**。集計時点により正式監査と件数は一致しない。
- これだけで外枠の予測確率・配当期待値・モデル精度向上を証明したことにはならない。とくに1レース内の決まり手は勝者の公式ラベルであり、動画による全艇の実際の航路/スタート隊形が観測済みという意味ではない。

## 前提となる公開説明
- BOATRACE公式の「まくり差し」：3〜6コースから一部艇をまくり、前を行く艇を差して先着する戦法。 https://www.boatrace.jp/owpc/pc/extra/enjoy/guide/level2/l2_02_02_03.html
- ボートレース戸田公式の2026/07〜09進入コース別成績：4コース勝ちの決まり手ではまくり55.5%、5コース勝ちではまくり差し66.0%（**当該場・当該期間の勝ち方の構成比**で、全出走レースにおける勝率ではない）。 https://www.boatrace-toda.jp/data/course_guide.html
- 実進入が変われば号艇とコースは一致しない。エンジンは実進入 `course` を先に評価し、買い目は `lane` に戻す。

## v0.2の試験ロジック
`app/tactical-1m.js` の `BoatTacticalModel.forecastOutside(input)` のみを呼んだ時に有効化。従来の `forecast(input)` はv0.1のまま。

1. 4コースのスタート攻撃：選手能力、モーター、平均ST、あれば合法な展示ST・展示タイムから算出した `go` を3・1コースと比較。ターン・直線も考慮。**相対攻撃強度が高い時だけ**頭重みを最大1.65倍まで調整。
2. 5・6コースの連動：直内のコースとの差と、その直内がさらに内側の艇を攻める可能性を別信号として計算。先行艇が攻めても後続が必ず上がるとはしない。
3. 条件付き2・3着：4まくり→5追走、5まくり差し→4/6連動、1逃げ→外枠2/3着、外攻め→1が2/3着残存を相互排他的な着順として120通りで比較。
4. 危険な一律外枠買いを避け、攻撃倍率が1.14以上かつ頭の相対シェアが4.5%以上の外コースに限り候補補完を許可。合計4〜12点・仮想50,000円。
5. 予想コードには結果・公式払戻・終了後の展示、勝利決まり手は渡さない。展示Fは速いSTとして加点しない。オッズ・潮向・動画物理解析・因果推定は未反映。

これらの数値は**実データで学習・校正済みの係数ではなく、検証用の仮説**である。モデル出力の `relative_share` は真の的中確率ではない。

## 前向き試験
`scripts/freeze_outside_trials.js` は既存 `freeze_tactical_trials.js` の締切3分安全線・ソース更新45分以内・6艇と5万円の入力検証を再利用する。自動収集後、同一の発走前データから旧1M戦法v0.1と外枠強化v0.2を別SHAで固定する。

保存先：`app/data/experiments/outside-YYYY-MM-DD.json`、稼働監査は `outside-status-latest.json`。既存の `app/data/experiments/YYYY-MM-DD.json` や正式予想、公式照合、仮想正式BUYは一切変更しない。実投票・通知はしない。

比較する指標：外枠勝者の頭捕捉、4・5・6が1/2/3着に入る場合の適合、まくり／まくり差しの勝者ラベル別の的中率、3連単的中率、仮想回収率、頭偏り、展示前/反映後別。**同じ発走前スナップショット**で比較し、あとから買い目を変えて過去収支を改ざんしない。まず100R程度を最低限の機能検証とし、希少な6号艇1着の評価はさらに長い期間を要する。
