# 1M戦術図アニメ改訂 — 2026-10-23

## 発見した問題
旧バージョンは3連単の**1着選手だけ**を「逃げ/差し/まくり/まくり差し」の主役として描き、その他の艇は順位と艇番から定型の経路に置いていた。このため、1号艇が2着・3着となる仮説であっても、その艇が**逃げるため先マイを狙う行動**が表現されていなかった。

## 対策（表示側のみ）
- 6艇をそれぞれ独立した「1M進入→旋回→バック」コースに分け、1コースの艇は勝ち・負けと無関係に先マイ/逃げを試みる模式経路を表示。
- 2コースの艇は差し、3/5コースはまくり差し、4コースはまくり、6コースは展開待ち等、艇ごとの戦術を明示。選択した買い目の頭候補ではその成立戦法を反映した別の経路とする（実際の戦法推定ではなく仮説）。
- 進入コースを保存していれば枠番ではなくコースを使う。失われた場合は枠番にフォールバックしてその限界を明記。
- 競走結果や決まり手をアニメの予想入力には使用せず、**出た着順を前提に戦法を逆算して事実とすることを禁止**する。

## 具体例
2026-10-23唐津1R：公式結果3-2-1、3号艇まくり差し、実STは1号艇.12 / 2号艇.09 / 3号艇.06。これは **振り返りにのみ**使用。ユーザー提供のJLC replay URLはツールで動画フレームを再生できなかったため、**1Mの間隔や旋回位置を実映像から検証したものではない**。

## 明確に未実装
- アニメの戦法はあくまで学習前のレース仮説、艇体間の物理衝突判定・実際の操舵角や速度、映像トラッキングなし。
- **展示・予想モデル自体の頭候補や1着確率の補正ではない**。1号艇過大評価を改善するには別途、スタート→1M分岐→バックの条件付きモデルと、その事前固定A/B試験が必要。
- 実映像を確認できるファイルをユーザーから受け取った際に、1Mでの内外関係と航跡をさらに調整する。
