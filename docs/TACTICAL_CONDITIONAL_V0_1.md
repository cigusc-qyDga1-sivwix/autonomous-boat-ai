# BOAT LAB：1マーク戦法連動型の研究版（v0.1 / 2026-10-23）

## どうして前回の買い目が変わらなかったか

前回の修正で24場の**弱い1コース補正**は予想エンジンに実装されたが、逃げ・差し・まくり差しの動きはアニメーション側にしか実装されていなかった。メインのアプリは発走前固定した元の買い目のみを表示していた。アニメーションはレース詳細を開いても停止しており、差し替えが見えにくかった。

## 今回の修正

- `app/tactical-1m.js`：選手の全国勝率、モーター2連対率、平均ST、利用可能なら展示ST・展示タイム・一周・回り足・直線値、会場別の1コース参考値、保存済み風速を入力。
- 実進入1〜6コースの逃げ・差し・まくり差し・カド攻め・外からの攻めの**仮説ごとの相対重み**を計算する。
- 頭の戦法が違えば、2着と3着の残り方に異なる条件付き係数を用いる。120通りの3連単を比較し、原則4〜12点に絞って仮想5万円を配分。
- 既存固定と別の「🧠 新・1M戦法研究版」として、レース一覧・会場別一覧・詳細に表示。
- アニメーションはデフォルトで新しい研究版の先頭候補を表示して自動再生。固定買い目と研究買い目を個別ボタンで切り替えられる。レース結果はアニメの計算材料には使わない。
- キャッシュ版v19とscript URLのv5クエリで新バージョンを確認しやすくする。

## 実データを使った動作テスト

2026年10月23日の保存済み168レースをオフラインで再計算したGitHub CI：
- 新しい買い目・配分と元の固定買い目に違い：**168/168レース**。
- 新研究モデルでトップ買い目が1号艇以外：**29/168レース**（旧モデルは0/168）。
- 頭が1コース以外となる候補も4〜12点の中に選ばれた：**162/168レース**。
- これは**買い目が変わったことの機能テスト**で、的中率の向上やモデルの校正、実測的中確率を意味しない。

## 未実装／制約

- 別研究版はブラウザで毎回再計算するため、**まだ発走前ハッシュを持つ正式固定予想ではない**。事後に表示したら事後研究と明示する。
- 元の固定予想、金額、SHA、公式結果、正式収支、BUY/WATCH/SKIPは変更しない。
- 1マーク分岐の条件付き係数は未学習の仮説。映像フレーム追跡、モーター整備・相性、潮流と風向の定量的関係、他艇の接触回避や物理的干渉は未実装。
- 予想性能を判断するには、**発走前にこの新モデルの出力を固定**し、未来の同一レースで旧版との前向き比較を行う必要がある。
