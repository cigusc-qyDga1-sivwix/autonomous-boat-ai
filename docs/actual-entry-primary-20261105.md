## 修正内容

1. 新しい展開計算は6艇のcourseを受け取り、攻め艇を実3〜6コースから選択する。抵抗艇はその内隣、外追走艇はその外隣を占める艇へ対応付ける。艇番で決めない。
2. 6コース攻めに外追走艇は存在しない。従来の5コース自動追走加点を行わない。5コースの浮上は他の仮説・基礎評価による余地を残すが、外追走の確定扱いをしない。
3. イン着外の相対量と買い目件数は1号艇固定ではなく、1コースを占める艇で計算する。選手別戦法履歴でもescapeの分岐を実1コースに対応させる。
4. 進入確認は `entry_evidence_status` に記録する。展示前や厳密な入力照合がない場合は `provisional_unverified`、6艇展示照合済みは `verified_exhibition`。枠なり仮置きを確認済み進入と呼ばない。
5. 新モデルIDを画面の選手評価・展開順位・根拠表示・監査へ登録し、別モデルや旧ラベルへのフォールバックを防ぐ。PWAキャッシュも更新する。
6. v2.0の根拠別点数制限・仮想5万円・WATCH/SKIPを維持。120点への拡張は再開しない。
