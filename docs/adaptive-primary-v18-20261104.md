# BOAT LAB v1.8 — 可変点数を正式メインに採用

2026-11-04、ユーザーから「比較検証ではなくメイン予想で点数を絞ったり広げたりし、これからのレースに適用」の指示。

## 変更点
- `INTERACTION_ADAPTIVE_MODEL = four-factor-v1.8-adaptive-points-primary-untrained` を2026-11-04 18:02 JST以降、締切前2分以上の新規レースに採用。江戸川は既存規則どおり除外。
- 旧モデルの点数（通常4〜20点）を**引き継がない**。6艇の着順全120通りの相対スコアから点数を自動決定し、公式な仮想5万円を **100円単位**で配分。購入実行なし。
- 候補を上位から並べ、正規化エントロピー（展開の曖昧さ）と評価スコアの累積相対質量・トップとの相対比で採否。採用点数は4〜120で変動し、6・12・20・40等の固定上限は持たない。ただし数式の閾値は未校正。
- 1号艇着外の候補が相対的に十分有力なら既存の安全弁を適用する。無条件に1号艇着外を混ぜない。
- メタデータ`interaction_primary.point_policy`に評価分散・目標カバー範囲・実際の点数・相対スコア比を保存。旧モデルの買い目は**監査記録**としてのみ残し、新正式予想の点数・金額を決めない。
- 表示用モデル名・アニメーション表示名、`scripts/forecast_audit.py`の可変点数判定も更新。
- v1.7までの固定SHAは変更しない。締切まで余裕があるレースは従来の新モデル昇格処理でv1.8の新スナップショットを追加する。
- 正式予想としての分類は他のモデルと同じWATCH（利益優位・オッズ未確認）。展示未反映は暫定、展示反映後の最終適格性ゲートは維持。

## 注意
- `relative_score`は学習済み確率ではない。多数点に広がっても的中率や回収率が向上するとは限らない。
- 1〜120通りは「採用候補の論理範囲」であって、毎回大量に購入する意味ではない。買い目は展開の分岐の強弱から増減する。
- 直前の締切済みレースに遡って新予想を書き込むことは禁止。
- 元の50,000円は研究用の仮想資金。実投票機能は存在しない。
- 自動取得・公開アプリ更新はGitHub mainへの統合と別の確認事項である。
