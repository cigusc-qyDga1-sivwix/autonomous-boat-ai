# BUY候補・前向きシャドー検証（2026-11-17開始）

## 目的と運用境界

- 目的：発走前に予測された相対的な頭候補の強さを基に、BUY候補がWATCH／SKIP候補より高い的中率を示すか、**前向き**に検証する。
- **BUYは研究上の候補ラベルであり、正式BUY・期待値プラス・実投票の推奨ではない。** オッズ未取得のまま収益性を主張しない。
- 現行の正式予想・買い目・配分・累計収支・正式分類 WATCH は変更しない。研究用データは `app/data/experiments/buy-shadow-YYYY-MM-DD.json` に保存し、後から上書き分類しない。
- 結果・払戻・オッズを判定時の入力にしない。公式結果照合は別ファイル `app/data/experiments/buy-shadow-eval-latest.json` のみ。
- 江戸川は対象外。進入変更、欠場、返還、未検証の展示、SHA不一致、締切直前・締切後、正式固定でない記録は新規ラベルを生成しない。

## 事前登録した暫定条件 v0.1

全条件：同一日、展示6艇照合済み、正式スナップショットSHA一致、予想固定済み、判定の実行時点で締切まで2分以上あること。

- BUY候補：頭の相対スコア集中度 `>=0.62`、首位と次点の相対スコア差 `>=0.40`、保存済み3連単点数 `<=10`。
- SKIP候補：頭の相対スコア集中度 `<0.37` またはスコア差 `<0.12`。
- WATCH：その他、または判定用スコアが未取得。

これらの数値は **暫定的な研究条件** であり、勝率や収益率が校正済みであることを意味しない。11月17日の結果を見て同じ日のルールを変更しない。サンプル全体で少なくとも100R程度の共通・公式照合を確保し、場・グレード・1号艇頭／外艇頭別の偏りも見る。

## 2026-11-23 以降：点数中立BUY候補 v0.2

- 正式予想の展示・締切前・6艇・SHA等の安全ゲートは継続する。
- BUY候補の数値条件は頭の相対スコア集中度 `>=0.62`、首位と次点の差 `>=0.40` のまま。
- **買い目点数 `<=10` の制約を撤廃する。** 12点・18点・24点など点数が多いだけでBUYからWATCHに下げない。実際のレース予想で生成できる点数上限は別設定のままで、今回の変更だけで24点を生成するわけではない。
- 強い根拠がない（相対スコア分離不足）、展示未照合、締切後などのWATCH/SKIP・判定保留は維持する。多頭混戦を根拠なくBUYに昇格しない。
- ルールIDは `relative-head-separation-point-neutral-v0.2`。11月22日以前はv0.1として評価・凍結し、過去のBUY判定や公式成績を再計算・書換えしない。
- BUYはあくまで**研究用ラベル**であり、オッズを用いた期待回収率や実投票の推奨ではない。正式買い目・配分は変更しない。
- 改善評価は発走前固定のルールID別に、BUY/WATCH/SKIPの件数、点数帯、外艇頭の捕捉、的中率、仮想回収率を分けて行う。

## 事後照合ルール

- BOATRACE公式の着順、公式確認フラグ、予想SHAの一致が揃う場合のみ集計。欠場・返還・競合・未確定は未照合とする。
- 分母は「発走前に判定を固定したレース」、的中率分母は「そのうち公式照合済みのレース」を区別する。
- 各群の `固定R / 照合R / 的中R / 頭抜けR / 2着抜けR / 3着抜けR / 保留R` を報告。元の仮想5万円配分は変更しない。
- 勝ち筋の集中度が高いだけで偏った買い目になっていないか、1号艇中心のBUY候補に偏らないかを再検証する。
- 同日結果による後付け修正・遅延生成は禁止。公開時刻と判定時刻の差も監査する。

## 実装と継続運用

`scripts/buy_shadow_trial.py` の `freeze` を正式予想が保存された後、別枠の GitHub Actions で実行・コミットする。一次レースの保存に失敗しても既存正式予想処理は止めない（`continue-on-error`）。

公式結果の別ワークフローでは `evaluate` が保存済みラベルだけを照合し、公式情報によってBUY/ WATCH/ SKIP分類を書き換えない。

テストは `python -m unittest discover -s tests -p test_buy_shadow_trial.py -v`。GitHub Actionsはベストエフォートであり、分単位の締切到達を保証しない。収集時刻が締切に間に合わないレースは無理に含めない。
