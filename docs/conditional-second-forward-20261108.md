# 1着→2着条件付き分散の前向き試験（v0.1）

2026-11-08。目的は「1着は当たったのに2着を外す」不的中を減らすため、正式v2.2の買い目採用段階を別の試験ルールで比較すること。

## 試験版の処理
- **正式予想は無変更。** 既存の interaction_primary.ranked_outcomes（同一発走前入力の120通り、相対評価）だけを読む。結果、払戻、実際のST、映像、事後学習係数は参照しない。
- 最上位候補を維持し、上位N位の相対評価の75%以上という研究用範囲内から、1着→2着の異なる組み合わせを ceil(N*0.6) 組まで優先する。残りは元の相対評価順に埋める。**75%・60%は仮置きであり、学習済み確率ではない**。
- 既存の正式予想と**同じ点数**、双方仮想5万円、1000円単位。3着は既存120通りの中の候補に限る。
- 6艇実進入と展示データの確認を通過した ticket_status=formal のみ。最新版ソースが45分以内、元予想と試験版の固定が締切5分より前、元SHA存在が必要。登録済みレコードは不変。
- app/data/experiments/conditional-second-YYYY-MM-DD.json が独立した試験台帳。後から保存された正式予想とのすり替えを防ぐため、**正式予想の元SHAが公式照合時のSHAと一致するペアのみ**を評価する。GitHubコミット時刻が締切後だった記録は前向き比較から除外する。

## 合格条件
- GitHub ActionsのCIがグリーンであり、初回の前向きレコードに検証可能なコミット時刻がある。
- 前向き100R以上、同一R・同一点数・同一仮想資金で的中率、回収率、1・2着一致率、3着漏れ、場別・頭艇別を比較。
- 同一Rの終結果に後知恵の点数変更、閾値チューニングを適用しない。効果がなければ採用しない。
- 自動BUY、実投票、正式買い目・過去予想の改変はなし。未学習・未校正の試験版で、的中改善は現時点では未証明。
