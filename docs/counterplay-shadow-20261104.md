# 相手の抵抗・攻め不発・第三艇浮上の検証版

## 結論

船足評価をそのまま攻め成功へ寄せず、「攻め切る」「内艇が受け止める」「攻め艇が着外」「競り合いで別艇が浮上」の4分岐を候補として列挙する独立試験を追加した。相手の心理・実際のマーク・航跡や妨害を観測したと主張しない。通常の競り合い・牽制の仮説であり、反則としての妨害を予測する処理ではない。

既存正式モデル、保存済み買い目、v0.2、日次設定は維持する。前の候補分散試験PR #157とは独立。追加した試験には未校正の補正案も含むが、下記の事後比較では悪化したため採用保留。分岐生成の実装と成績改善を混同しない。

## 現行コードで確認した限界

`app/tactical-1m.js` のfour-factor経路では、同じ `combined_multiplier` をgo/turn/straight/overallに使用する。これは独立した伸び・旋回の測定ではない。また、openChasers経路のcoupled_v06はanalysis_onlyで、相手との連動はchaserスコアへ適用しない。表示されている艇間連動を、買い目への完全反映と見なさない。

## 追加した処理

- 6艇の実進入を必須とし、攻め艇の内隣艇を実コースで特定する。号艇から固定しない。
- 6艇展示タイム完備、両艇の基礎選手/モーター/平均STがあるときだけ攻め仮説を候補化する。
- 直前タイム差、平均STと合法展示STの比較、相対能力から候補化。展示Fを高速スタートとして加点しない。
- 内艇が大きく遅れず、選手能力が近いときに抵抗可能性を記録。オリジナルまわり足が両艇にあれば別に比較し、なければ未確認とする。合成能力を旋回実測へ読み替えない。
- 競り合い時に相対能力・ST条件を満たす第三艇を候補化。差し場の実在を観測したものではない。
- 各分岐に上位3通りの候補、対照買い目と試験買い目への採否を記録。攻め失敗分岐では攻め艇の着外も許容する。
- 「強いからマークされる」「人気だから失敗しやすい」を入力せず、強い艇への一律減点をしない。
- 仮補正は抵抗下の攻め0.94、内残り/第三艇1.04、累積倍率0.85〜1.08。未学習で成功確率ではない。実行には明示フラグが必要。
- 選択アルゴリズムの影響を混同しないよう、同じ全120通りの選別を使う無補正対照も出力する。頭候補は変わり得るため、旧v0.2の頭保持試験には混ぜない。
- 点数・総仮想5万円・金額分布を合わせる。相手の抵抗根拠がないレースでは対照の組合せ・配分をそのまま維持する。

不足しているのは、実映像による実際の受け止め・旋回ミス・競り合いの正解ラベル、選手別の抵抗/攻め成功実績、時系列情報による前向き評価。内部固定時刻の検査と外部公開時刻の監査は別である。

## 接続範囲

Nodeブリッジで `counterplay_shadow_trial:true` と、明示的な `cutoff_iso_jst` がある場合のみ独立 `counterplay_shadow` を出力する。`frozen_at_utc < cutoff_iso_jst` を検査し、展示前・時刻欠損・重複進入は試験を利用不可とする。失敗しても正式出力を抑止しない。

Python日次入力、画面表示、前向き保存・集計は未接続で、自動稼働の主張はしない。モデルの数値補正を本採用するPRではなく、分岐を検証するためのレビュー用実装。
