# 正式買い目の採用基準

2026-10-25のユーザー指定。展示情報取得後に再計算し、締切前に固定した最新版を正式買い目とする。

- 6艇の実進入・展示ST・展示タイムを確認する。既存の締切前安全余裕（最低120秒）を維持する。
- 再計算の結果が展示前と同じでも、展示反映版の固定が完了すれば正式とする。
- 展示前は暫定、未確認・欠損・締切後取得は正式化を保留。前付けでも例外なし。
- 結果照合は最新版のSHAに対応させ、正式版だけの当日・累積仮想収支を表示する。全研究予想の成績は別表示とし、過去の固定買い目・SHAを改変しない。
- 正式買い目の指定はBUY判定や実投票の承認ではない。通知OFF、実投票なしを維持する。
