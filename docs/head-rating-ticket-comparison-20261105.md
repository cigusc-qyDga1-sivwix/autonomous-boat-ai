# 1着相対評価と買い目配分の比較表示

確認日: 2026-11-05 JST。参照: commit `4ba964c7af448f5d15496311662f49e914d0c5d3` の `app/data/live/latest.json`、更新時刻2026-11-04T22:09:28.780345+00:00。

## 調査結果

11/5の144R（v2.1 132R、v1.3 12R）を照合。新primaryの保存された `head_course_shares` と `interaction_primary.main_role_shares.first` は丸め誤差内で一致した。別モデルの数値が混入している事実は今回のデータでは確認できなかった。

ただし、全展開での1着評価1位と、採用買い目の頭別配分最多が一致しないケースは41R。単純に最多配分の最初の艇だけ比較すると44Rだが、うち3Rは同額配分で、食い違いに数えない。評価1位の艇が頭として全く買われていないレースは0Rだった。

例: 三国5Rは③の全展開1着相対評価25.38%（表示25.4%）が最上位。一方、採用買い目の頭別仮想配分は①31,000円、③19,000円。全120組を合計した周辺評価と、点数制限・2/3着条件で選別した組み合わせの配分が別の量であるため。これを同じ推奨順位に見せる表示は説明不足である。配分割合に円グラフを合わせて数値を改変してはならない。

## 変更

- 円グラフは保存済みモデルの1着相対評価を維持し、買い目・配分から確率を逆算しない。
- 新primaryは `main_role_shares.first` を参照し、保存head sharesとの一致を検査。不一致・欠損なら非表示とし、別モデルの再計算で補完しない。
- 同じスナップショットの `bets` から6艇の頭別採用点数・仮想金額・配分割合を直接集計して、評価割合と並べる。保存 `ticket_role_counts` がある場合も照合し、不整合なら比較保留とする。
- 評価トップと最多配分を併記し、互いのトップ集合に重なりがない場合に差を明示。同額トップは誤警告しない。
- 全展開での評価、選択された3連単の配分、未測定の収益性を区別する。実際の1着確率とは表示しない。
- JS/CSSのバージョン指定とPWAキャッシュを更新する。

## 検証

`node app/tests/head-share-chart.test.js` と `node app/tests/primary-evaluation-alignment.test.js` 成功。144R全ての合計点数・50,000円配分を照合し、逆転41Rを再現した。テストは評価値の非改変、同額トップ、壊れた買い目、保存評価の矛盾、古い採用点数、HTMLエスケープ、同じ保存データの不変性を確認。

今回の修正は比較表示とデータ整合性検査。予想ロジック・採用組み合わせ・配分・過去成績は変更しない。配分の妥当性が改善したとの主張や、今後の的中率・回収率の改善を意味しない。配分自体の妥当性は別に結果検証が必要。
