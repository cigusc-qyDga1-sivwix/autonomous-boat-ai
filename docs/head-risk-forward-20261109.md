# BOAT LAB 発走前・1着リスク監視 v0.2（研究・読取専用）
更新日: 2026-11-09 JST

## 目的
11月9日の途中集計では「1着候補を外したケース」が相対的に増えた。一方、日次比較だけでは開催条件・モデル差の因果を断定できない。そのため、買い目を結果から補正せず、**発走前に保存されたモデルの1着相対評価と買い目配分の矛盾**を明示し、独立した前向きの警告別成績を記録する。

## 改修
1. **強豪判定に依存しない頭抜け警告**: 相対1着評価の上位2艇が接近（1位が45%以下、差10pt以内）し、モデル評価上の頭候補（首位の70%以上かつ12%以上の相対値）が買い目の1着に含まれなければ `MODEL_CLOSE_HEAD_UNCOVERED`。従来は「全国勝率6.0以上4艇」も必要だったため、一般戦の頭接近を見落とし得た。
2. **イン艇への資金集中警告**: 実進入1コースの艇（必ずしも1号艇とは限らない）の買い目配分が75%以上、同艇のモデル相対1着評価が55%以下、差20pt以上、かつ展示フェーズなら `INSIDE_TICKET_CONCENTRATION`。買い目の1点目だけでなく、全チケットの `virtual_yen` を計算する。
3. **正式履歴不変・研究表示**: 保存済み正式買い目、点数、仮想5万円、配分、BUY/WATCH/SKIP、過去スナップショットを変更しない。古いv0.1の警告には新しいラベルを後付けしない。出走表6艇と進入コース1〜6の重複なし、相対評価の和、全買い目金額を検証し、欠損時は警告を断定しない。
4. **公式結果監査**: 凍結時から保存された `risk_flags` だけを `by_head_risk_formal` で分類。正式対象かつ公式結果照合が確定したレースのみで、的中・1着捕捉・回収を集計。未照合・欠場・返還競合・暫定は除外。

## 制約
- `relative_share` は **未校正の相対スコア**。的中確率ではない。
- 差分閾値は **検証前のヒューリスティック**。公式着順や当日の配当を見た調整を一切行わない。
- 警告は自動的な買い目追加・オッズ操作・自動購入・正式昇格ではない。
- `head_coverage_warning` は非強豪でも発火するよう修正。既存 `STRONG_FIELD_CLOSE_HEADS` の分類基準は維持。
- 1コースの相対重みと全買い目金額比は、モデル予測確率と最適投資比の同値ではない。乖離は調査優先度の代理指標に過ぎない。

## 確認基準
- 単体テスト: `python -m pytest -q tests/test_strong_field_diagnostic.py tests/test_forecast_audit.py`
- UI: `node --check app/app.js` とアプリ詳細画面の読み取り専用警告表示
- 必須: プロジェクト既存のPython/JS CIおよびPages配信確認
- **前向きの共通100R以上**で、発走前固定の警告あり・なし、公式確定後の1着捕捉率、同一点数条件での的中・回収率を場・グレード・展示完備別に比較。正式変更は別PR・独立モデルID・独立SHAと昇格根拠を要する。
- 「警告ありの日ほど外れる」という事後相関だけで頭候補を追加しない。
