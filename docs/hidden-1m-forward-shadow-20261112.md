# 2026-11-12 — 見落としやすい1M展開の前向き研究 v0.1

## 目的
BOAT LABが「本命が失敗した」と事後に説明するだけでなく、**正式予想で拾えていない別の勝ち筋を展示反映後・締切前に発見**し、結果が分かる前に候補と独立検証用の買い目を固定する。

## 分岐（実際の動きではなく未校正の仮説）
- `OUTER_ATTACK_FOLLOWER`: 外3〜5コースの攻め艇 → 直外の艇が追走 → 1コース残存
- `OUTER_ATTACK_INSIDE_SURVIVES`: 外攻め艇 → 1コースが2着残り → 直外追走艇
- `ATTACK_OVERRUN_INNER_COUNTER`: 攻めが流れた場合に2・3コースが逆転 → 1コース → 仕掛け艇

## 発走前の採用根拠
同一レースの実進入6艇、展示ST・展示タイム、平均ST（補完値禁止）、オリジナルまわり足を確認し、外側の候補艇が**内側の1コース艇より平均ST 0.02秒以上優位かつまわり足0.03秒以上優位**な場合のみ分岐生成。通常展示タイム単独、展示F、推測の牽制・引き波軌道だけでは候補を作らない。直外追走は展示タイム・まわり足の相対水準で別に検査。

これらの閾値は**仮説**であり、実測のまくり成功率・万舟確率ではない。場ごとの収益性や過去データでの精度改善を保証しない。

## 境界
- 発走締切より2分以上前に取得・計算した、6艇完備の展示反映済み予想だけ。
- 判定対象は江戸川を除く場。元データを欠く場合や基準未達なら候補なし。
- 正式v2.5の120組・買い目・点数・仮想5万円・BUY/WATCH/SKIP・保存SHA・収支を変更しない。
- 研究候補が正式で未採用でも**勝手に追加投票しない**。研究用の1点差替案は、既存の先頭4点を保護、ペア重複がある末尾と同等の相対評価を持つ時のみ発走前に凍結。同じ点数・仮想5万円で、正式とは別の資金配分。
- `hidden_path_shadow` は `model_role=research_shadow`、`not_formal=true`、`result_data_used=false`。アプリでは正式買い目と区別して🧠展開候補と理由を表示。
- 公式払戻のみで照合。`hidden_path_forward_comparison` に、頭・2着の救済と新たな抜け、3連単的中、仮想回収率を双方記録。結果未確認・中止・返還・SHA/締切不整合を除外。**事後生成を禁止**。

## 検証・昇格判断
`tests/test_hidden_path_shadow.py` と `tests/test_hidden_path_audit.py` で欠損、展示F、締切後、結果混入、不変条件、公式照合を確認。

今後の独立した**共通100R以上**、さらに場別・攻め手コース別に、同一点数・同条件で勝ち筋捕捉率、3連単的中、仮想回収率を比較。高配当1件の寄与だけを根拠に正式化しない。負け側（既存の的中を失う例）も同時公開する。現段階で正式版へのロジック昇格はしない。
