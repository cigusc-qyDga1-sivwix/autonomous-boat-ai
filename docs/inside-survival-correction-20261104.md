# BOAT LAB v1.7: 1号艇残存バイアスの整合性修正 (2026-11-04)

## コード監査で確認した不一致
1. 上流の `features()` が既に進入コース・平均ST・展示タイムを含む相対ウェイトを計算しているのに、`interaction_scenarios.py` がそれらを再加算した。
2. 旧モデルの `head_course_shares` を新モデルの正式画面で表示し、新しい3連単との説明が食い違っていた。
3. 23場別・気象の上流補正後ウェイトではなく、補正前の `relative_weight` を新モデルへ渡していた。
4. 従来の4展開は外攻め成功でもイン残存に寄り、全120通りの混合上位4〜20件に絞る際、1号艇着外の条件付き展開が落ちることがあった。
5. 新モデルの説明文が後段で旧4因子の共通説明に上書きされていた。

## 修正
- 基礎能力計算は上流に集約。展開側では二重補正を撤廃。
- 5分岐目 `inside_displaced` を追加し、各仮定パスで1号艇が3着外となる相対質量を診断記録。
- 1号艇が3着外の合計相対質量が0.25以上で、最上位着外候補がカットラインの0.55倍以上の評価なら、固定点数内で1点だけ着外候補を確保。1号艇圧倒的な条件では自動的に追加しない。
- 画面に出す先頭候補シェアを新モデルの120組から再計算。旧モデルシェアは別メタデータ。
- 23場／気象補正後の事前ウェイトを使う。
- 正式モデルIDを `four-factor-v1.7-interaction-inside-failure-untrained` に更新し、2026-11-04 12:30 JST以降に生成する予想へ前向き適用。これまでの発走前SHA・保存済み予想を上書きせず、締切まで安全余裕があれば従来のモデル昇格処理が新バージョンの発走前スナップショットを追加可能。
- 5万円の仮想配分・旧モデルとの同点数対照・江戸川除外・結果混入禁止は維持。

## 限界
- 0.25 / 0.55 の選択閾値や、攻撃成功・イン着外の展開重みは**実績で推定された確率ではない**。1号艇着外を必ず買うための固定ルールにもしていない。
- 外枠の着順が増えた事実は精度改善の証明にはならない。同一レースの発走前固定比較・的中・回収・3着抜け・校正で確認する。
- 修正のテスト成功と、公開アプリに反映されること、実績の改善は別途確認する。
