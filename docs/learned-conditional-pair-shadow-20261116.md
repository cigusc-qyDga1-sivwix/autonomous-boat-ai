# 学習済み正式モデル × 1M条件付き2着研究（2026-11-16）

## 接続範囲

現行の統計学習による正式3連単は変更しない。発走前に生成された
**学習モデルの全120通り**を出発点に、既存v2.6の「外艇攻撃と2着連動」を
同一レース・同時点の独立研究用シャドーとして凍結する。

- 正式予想: `learned_formal` の `bets`、配分、モデルID、分類は不変。
- 研究用: `learned_conditional_shadow` の `control_bets` と `shadow_bets`。
- 追加金額ゼロ。両方とも仮想5万円、同一点数。
- 1着ごとの周辺スコアは厳密保持し、2・3着条件付き分布のみ再評価。
- 1号艇を一律に弱めない。結果・着順・払戻・オッズ・事後STは入力禁止。

## 発動条件（失敗時は研究版を保存しない）

1. 学習済みモデルのSHA一致、既存の学習鮮度ゲート合格。
2. 江戸川を除いた展示確定レースで、6艇の数値展示が保存時に一致。
3. 締切120秒以上前に、正式予想が発走前生成されている。
4. 6艇の進入、平均ST、展示ST、展示タイム、まわり足が利用可能。
5. 既存v2.6の攻撃根拠条件を通過しなければ、シャドー予想も無変更。
6. 過去のスナップショットは再計算・上書きしない。

実際の入出力照合成功後にだけ研究予想を保存するため、
`prediction()` 内で事前に追加したと偽ることはしない。
採用元は新規の `scripts/learned_conditional_shadow.py`。

## 評価基準

最低100Rの発走前固定・公式結果照合・同一点数ペアを集める。
頭捕捉（理論的に同じ頭周辺スコアだが買い目は変化可能）、
2着抜け、3着抜け、3連単的中、回収率、場別・開催グレード別に比較。
返還・欠場・公式未確定・入力不備・発走後生成は評価母数に入れない。
**現時点では収益性は未検証で、正式への無条件反映を許可しない。**

独立した正式モデル昇格には、実績検証に加え別PR、CI・発走前保存・表示監査が必要。
