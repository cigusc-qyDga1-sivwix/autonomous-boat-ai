# BOAT LAB：蓄積学習モデル＋追い風／向かい風の正式買い目補正 v0.1

## 目的と適用範囲

利用者の明示的な依頼（2026-11-21）で、**新しく発走前固定する予想のみ**、
蓄積したモデル \`app/data/statistical/latest-model.json\` の3着までの条件付き順位を
維持し、現地直前情報の追い風／向かい風に応じて補正する。

- 既存学習器は出走・モーター・平均ST・実進入・展示・風速・波高の
  1/2/3着条件付き係数を既に学習している。**風向別係数は過去の結果から学習されていない**。
- 新機能 \`scripts/learned_wind_direction_v1.py\` は風向に対する
  **上限17%程度の対数スコア補正という未校正仮説**。
  新しい「学習済み風向モデル」や回収率改善の実証ではない。
- API提供元コード表で全24場共通：3～7=追い風、11～15=向かい風、
  17=無風、その他=横風寄り。真方位へ再変換しない。
  https://github.com/boatraceopenapi/api/blob/gh-pages/docs/v1/codes.md
- 6艇の実進入・展示データが揃い、**その予想実行時点の
  BoatraceOpenAPIの場内風**と認定でき、発走締切の5分以上前に固定された
  新しい展示予想だけで有効化。2m/s未満・欠損・Open-Meteo等の近隣予報・
  スタート展示不一致では旧学習モデルの買い目を維持。
- 風向と1着・2着・3着の相関は実運用の前向きA/Bで評価し、適用前の
  120通り分布・正式買い目と適用後を**同時刻**で保存する。
  外枠攻め、差し、イン残り、5/6の追走を弱く再重み付けするが、
  結果データ・払戻・オッズには一切アクセスしない。
- 既存のレース展開／専門家型配分が後段で買い目を変更することがあるため、
  研究用に**全ての既存処理を通した風向補正なし最終買い目**を別途算出。
  表示される正式買い目と同じ点数・仮想5万円の差分を
  \`learned_wind_direction_v1.actual_ticket_or_allocation_changed\` に保存。
- 学習モデルのSHA、学習対象R数、学習終了日、風向ポリシーSHA、取得元、
  固定時刻、補正あり／なし買い目を保存する。正式買い目は
  新スナップショットのSHAで保存し、既存の発走前固定版・公式成績を
  書き換えない。欠場・返還等の公式照合も別処理。

## 注意・未確認
- BoatraceOpenAPIの風向は**提供元での実観測時刻が含まれない**。
  取得時刻が締切前でも気象値自体の鮮度を完全には証明できない。
  WEATHER LAB公式beforeinfo差分監査は独立記録であり、現段階では
  **正式入力を自動認証したことにはならない**。
- 学習モデルが未生成・署名不整合・古い場合は、
  学習モデルへの昇格は行わず従来予想を続行する。
- 風向の効果は実運用の回収率・的中率改善を保証しない。
  G1/G3/一般、場、風速帯、カド／カド受け、1着・2着・3着抜けで
  分けて前向き成績を監査する。
- 完全な公式サイト映像解析・BOATCAST自動認識はこのPRの対象外。
