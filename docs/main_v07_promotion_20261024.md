# BOAT LAB 正式運用モデル切替：新v0.7メイン／旧方式検証用

切替日：2026-10-24（**GitHub main へ反映した時刻以降に新規作成する発走前スナップショットから**）

## 何がメインになるか

- `scripts/autonomous_daily.py` が `scripts/main_v07_bridge.js` を使用して、ブラウザ研究用エンジンと同じ `app/tactical-1m.js:forecastOutsideStart` (v0.7) の出力を canonical `bets` に格納する。
- 予想テーマは6艇連動、進入コースごとの内外ST先行差、4/5/6コースのまくり・まくり差しと2着追走、頭ごとの条件付き2着・その先の3着。
- 3連単4〜12点、仮想5万円。オッズなし・学習／確率校正なし・通知なし・実投票なし。分類は引き続きWATCHであり、券の購入を勧めるものではない。
- ブリッジ異常、ST計算異常、点数や配分異常なら**旧式にこっそり戻さない**。その予想の固定はエラー扱い。
- 本番の処理は各Rごとに時計を再確認し、締切の少なくとも3分前を必要とする。GitHubの配信時刻は正確な締切前を保証しない。

## 旧モデルは消さず、比較対象に固定

- 同じ時点の旧Pythonヒューリスティックの `bets`、`model_version`、`frozen_at_utc`、`sha256`、気象あり/なしの旧式内比較を `legacy_control` としてメインの凍結スナップショット内に同時保存。
- BOATRACE公式照合では canonical `bets` のみを主集計の `hit`, `virtual_payout`, `virtual_profit` とする。`legacy_comparison` は別枠の仮想集計で加算しない。
- `main_vs_legacy` は **主／旧両方が同じ発走前時点に固定されたRだけ** の照合。過去レースに旧式や新式を事後的に生成しない。
- 旧JS v0.1〜v0.6の独立SHA台帳・旧Python正式版、旧実験記録もすべて保存する。
- 同日で切替前後が混在する場合は、**各レースの `model_version` / `model_role`** を正として照合する。以前に固定済みの旧レースを書き換えない。既にある展示前版に新しい展示版を締切前に追記する場合は別バージョン・別SHAとして保存し、元の版を保護する。

## UI表示

- レースの第一の買い目、仮想配分、標準アニメは発走前固定した `r.bets` を使う。
- `model_role=main` の場合に「メインv0.7」と表示し、旧式の正確な固定買い目は「旧モデル検証」折りたたみで表示。
- 集計ページでは公式結果取得後 `main_vs_legacy` を別枠表示（モデルごとの仮想投資5万円・返還など要確認は計上しない）。
- 昔の `model_role` がない固定予想は「当時の旧モデル」として変えずに描画。

## 検証プロトコル

初期の最低100Rを目安に、同日・同Rのペアで以下を比較：
- 4/5/6の頭候補捕捉、2着候補捕捉、1着→2着の連動、3着紐抜け、3連単的中、仮想回収率、未取得・展示進入欠損の割合。
- 結果照合は公式のみ、発走前SHAから一切変えない。的中と回収率の向上はこのコード変更だけでは確証できない。
