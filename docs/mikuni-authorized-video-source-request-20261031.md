## 正規の直接動画入力先が分かった場合の接続条件

1. 取得済みの個人研究許可を前提に、配信元が案内する直接動画ファイル／APIの利用条件と技術的アクセス範囲を確認。
2. 配信元が承認したHTTPS動画ファイルのURLテンプレートはGitHub Actionsの**secret** `MIKUNI_VIDEO_SOURCE_TEMPLATE` に置く。許可されたホスト名だけをvariable `MIKUNI_VIDEO_ALLOWED_HOSTS` に指定。
3. 未承認のログイン、DRM回避、非公開API推測、ストリーミングURL抜き出しは行わない。
4. まず1レースのみで実映像の取得・デコード・6色候補追跡を監査し、正規取得の成功と正しい艇番識別を分けて評価。
5. 6艇の実映像ラベル／ターンマーク校正／追跡精度を独立に検証できるまでは正式予想へ自動反映しない。
