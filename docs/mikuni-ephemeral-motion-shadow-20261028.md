# 三国｜映像→数値→発走前試験予想の接続実験 v0.1

更新：2026年10月28日 JST。

## 実装したデータ経路

1. **配信元の許可した直接動画URL**：GitHub Actions secret \`MIKUNI_VIDEO_SOURCE_TEMPLATE\` と variable \`MIKUNI_VIDEO_ALLOWED_HOSTS\`。三国個人研究の自動解析についてのユーザー報告は尊重するが、JLC/BOATCAST/YouTubeの独立した配信元の利用条件は別。未設定の場合、動画自動読み込みは行われず、欠損が明示される。
2. **メモリだけで取得・デコード**：\`scripts/mikuni_video_ephemeral.py\` は最大120MBのMP4/WebM/AVI/MOV動画バイトをRAMで受け取る。FFmpegで最大48フレームを標準出力に変換して、OpenCVで色領域を分析。MP4でシークが必要な場合はLinuxの匿名\`memfd\`を使用する。元動画もフレーム画像もGitHub／データベース／公開サイトに保存しない。
3. **色領域候補の数値研究**：最大640px相当の画像から赤・青・黄・緑の領域の中心と画面上の見かけの変動を抽出。出力は\`app/data/experiments/mikuni-video-auto-YYYY-MM-DD.json\`に、日時・映像SHA256・候補の数値だけ。**白黒・グラフィック・水面やカメラパンは自動識別されていないため、表示色を艇番や選手能力として断定しない。見かけのpx/sは実速度m/sではない。**
4. **6艇の検証済み軌跡**：正式な動画起点の試験買い目を作るには、独立に検証された1〜6の全艇の軌跡・正しい艇番・校正された水面座標・カメラ移動補正・高信頼度のIDが必要。形式 \`boatlabs.verified_six_boat_tracks.v1\` のレース別台帳を \`app/data/experiments/mikuni-tracks-verified-YYYY-MM-DD.json\` で受け取る。**現時点ではこのファイルを生成する実映像トラッカーは未実装。色領域候補をこの形式に昇格させない。**
5. **発走前のA/B試験予想**：\`scripts/mikuni_video_shadow.py\` は検証済み6艇の位置からスタート早期・後期／ターン入口・出口の区間速度を計算。各艇の相対指標で既存の正式v1.5の3連単買い目配分を試験的に再配分し、\`app/data/experiments/mikuni-video-shadow-YYYY-MM-DD.json\`にSHA固定する。**締切120秒前・確認済み展示6艇・正式v1.5の既存SHA・同じ映像SHAの6艇を全部確認できた場合だけ**作成。レース後の結果・配当・オッズは一切使用しない。買い目の自動配分式は未校正の試作で、正式BUY・収支・実投票には影響しない。
6. **BOAT LAB表示**：\`app/turn-vision-pilot-20261028.html\` で、映像取得済みR・検証済み6艇・試験予想SHA固定R・正式予想非変更を別表示。

### 取得元を有効にするには

- \`MIKUNI_VIDEO_SOURCE_TEMPLATE\`：配信元の使用許可がある、直接HTTPSで動画ファイルが返るテンプレート。BOATCAST/JLCの視聴ページURLやYouTubeの動画ページURLは**直接動画ではない**ため設定しない。
- \`MIKUNI_VIDEO_ALLOWED_HOSTS\`：配信元の承認済みのホストをカンマ区切りで記載。HTTPS・ホスト・リダイレクトとデータサイズ／コンテナを検証する。
- 独立トラッカーの精度検証完了後は、同一レース・同一映像SHAの水面座標で6艇を追跡できた場合にのみ、前向き検証用の軌跡台帳を生成する。

- 6艇の合成検証用入力に限り、シャドー配分を¥50,000・¥100単位で固定し、再実行でSHA不変であることを確認。
