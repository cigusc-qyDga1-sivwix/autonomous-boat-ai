# 三国の無人動画処理：手動初期位置を必須にしない経路

2026-10-28。目標は利用者によるレースごとの動画選択・開始時刻入力・艇や岸のクリックを必要としない完全自動運用。この変更はそのための **未学習の画素候補解析経路** を追加する。実映像で検証済みの艇番認識や物理計測の完成を意味しない。

## 自動で実行する処理

1. 既存の三国展示台帳から対象レースを認識し、設定済みの配信元HTTPS動画をメモリに受け取る。
2. 最大48枚・5秒間隔のプレビューをメモリ内でデコードし、色候補のある最大3区間を自動選択する。利用者による開始位置入力は不要。
3. 各候補区間を0.5秒間隔・最大48枚で解析。6色の領域候補を検出し、背景特徴点を自動選択してカメラのパン・ズーム補正を推定する。
4. 時系列の色候補を自動関連付け。複数の同色物体、特徴点不足、追跡飛び、場面切替、静止グラフィックは測定に使わず、推測で補間しない。
5. 数値候補と状態だけを既存研究JSONへ保存。同じ動画SHAと解析バージョンは再取得せず、旧版の解析は同一SHAに限り再解析する。

旧来の手動6艇・岸6点の追跡は比較用として利用できるが、無人経路の実行条件ではない。手動注釈ファイルがなくても上記の処理は実行される。

## 実映像で未検証の項目

`lane_color_hypothesis`は色による艇番の仮説。反射・航跡・字幕・他の物体を除き切れたことや正しい艇番の証明にはならない。自動で計算した補正後px/sも艇の実速度m/sではない。

- 実映像での艇番認識・追跡精度：未検証。
- 水面のメートル校正、1マーク中心、スタートライン位置：未確立。
- 実速度、旋回半径、スタート後0〜5m等の区間計測：未検証。
- 正式予想・試験予想への自動昇格：行わない。既存の独立検証済み軌跡ゲートを維持。

これらの項目は未取得として残し、色候補の計算成功を「動画学習済み」へ読み替えない。

## 入力接続と運用状態

無人取得の入口は引き続き `MIKUNI_VIDEO_SOURCE_TEMPLATE` と `MIKUNI_VIDEO_ALLOWED_HOSTS`。三国への個人研究利用の確認という経緯は保持する。配信元が提供する動画ファイルの接続先がない場合、実行記録は `DIRECT_MEDIA_SOURCE_REQUIRED` となり、動画解析の成功件数は増えない。設定値や元映像を公開しない。

この変更時点では実映像の入力接続は未設定で、実映像の解析成功は0R。レースごとの手動操作を前提とした運用へ戻さず、入力接続と実映像での自動識別・校正が今後の未完了事項。

## 検証

`python -m scripts.run_mikuni_vision_tests`

OpenCV・NumPy・FFmpegを必須にし、依存関係不足や1件でもテストのスキップがある場合は失敗にする。生成したAVIを実際にメモリ内でデコードし、手動注釈なしの候補検出・自動区間選択・カメラ補正・重複取得防止まで検証する。実競艇映像の精度試験とは分けて扱う。
