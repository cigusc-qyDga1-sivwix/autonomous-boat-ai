## 修正の狙い

- 4/5/6が頭：自分の**直内コース**より想定STが早く、能力・行き足・旋回が一定以上のとき、まくり先行、内のカベ崩れ、まくり差しの差し場を考える。
- 4/5/6が2着：頭にならないケースでも、①先マイ残存、③④の仕掛け失敗/成功、外艇追走・攻め残りを独立して評価する。自艇が頭評価を増やしたために**周辺2着割合が数学的に下がっても誤判定しない**。
- 内艇が速い場合・外艇が弱い場合：無条件加点や④⑤⑥枠別購入枠は設けない。
- 枠番とコースは区別：前付けの可能性があり展示進入が未確認なら買い目は最終確定させない。
- 展示F（マイナスST）：マイナス値を「驚異的に速いST」として加点しない。
- 内側との差：平均STと有効な展示STの保守的な合成値。実際の本番のスリット位置・機力加速やF確率を計測したものではない。
- 数値の閾値・係数は**未校正の仮説**。公式が示す統計値をそのまま個別選手の勝率に流用しない。

## 比較と研究

- `app/tactical-1m.js`: `forecastCoupled()` を不変に保ち、新設 `forecastOutsideStart()` が v0.7 のみ加点・着順候補の再確認を行う。
- `scripts/freeze_start_trials.js`: 同じ発走前固定スナップショットから v0.6 と v0.7 を作り、締切3分超前・データ鮮度45分以内・SHA固定の条件で別台帳に保存。結果が出た後に作成/追記した「予想」は公式な前向き検証に混ぜない。
- `scripts/research_start_gap.py`: 過去の展示STと公式準拠で整形された暫定結果のコース順位の**記述集計のみ**（4/5/6の頭、2着、まくり・まくり差し）。2艇の展示ST差 `ST(直内艇) - ST(対象艇)` が +.03秒以上 / ±.03秒未満 / -.03秒以下 / 欠損（F含む）で分類する。分母に対する各着順件数を明示。
- この集計は**本番STと着順の因果分析ではない**。展示ST時点と最終レースの入着に相関があっても、実コース相違・調整・天候・選手能力の交絡が残る。
- 機械学習を名乗るにはレース本番ST、実進入、実映像の「スリット先行／中凹み／壁の有無／まくり成立／差し場／2M順位」を観測し、日付分割された十分な教師データと発走前固定A/Bによる外部妥当性が必要。

## 最低限の評価
毎R事前固定を照合して、
1. 4C/5C/6C の頭候補捕捉、2着候補捕捉を個別評価する
2. 1着固定後の2着条件付き捕捉率（*頭評価の変化で全体2着比率が変わる問題*を切り分ける）
3. 1・2着一致なのに3着外れ、3連単的中率、仮想回収率を分けて比較する
4. サンプル少数／データ欠損／前付け疑いを層別し、単なる日別上振れで正式モデルを置き換えない
