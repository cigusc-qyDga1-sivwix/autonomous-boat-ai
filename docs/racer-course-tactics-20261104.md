# 選手×進入コース×戦法の評価 — 2026-11-04

## 目的
攻撃艇と抵抗艇の相性を、**過去の実際の機会数**を分母として評価する。実際のデータがない選手を「まくりが得意」と決めつけない。

## 実装
- `scripts/racer_course_tactics.py`: 進入コース別の逃げ、差し、まくり、まくり差し、抜き、恵まれの勝利件数 / 出走件数と、まくられ・差され等 / 該当機会件数の証拠付きプロフィール。
- 事前の識別子・コース・観測終了時刻・元データSHAを照合。ターゲットレース時点以降の観測は拒否。
- 少数試行はBeta-Binomial事前分布で平滑化。事前確率・強度は**未校正の研究値**であり、学習済み能力評価ではない。
- 牽制・防御は意図や心理を推測しない。進路の失敗や成功を観測結果として表現する。
- `pairwise_note`: 攻撃側のコース別戦法頻度と守備側の被攻撃結果を、サンプル条件付きで結び付ける。予想確率と呼ばない。

## 運用条件
1. 使用権限のある公式・許諾済み過去レースデータから、選手ID×進入コースごとの分子と分母を作る。**決まり手別の勝利構成比を出走あたり成功率と混同しない**。
2. ターゲットレースより前に完了したレースのみで集計し、データSHA、観測時点、サンプル件数、集計期間を監査する。
3. 1Mで誰が誰を攻撃したかの「機会数」は3連単着順だけでは復元できない。映像検証・有効な展開ログがない限り欠損として扱う。
4. 戦法評価が未取得・不足の場合は既存の正式モデルへ影響させず、誤った係数は追加しない。
5. 同一レース・発走前SHA固定で旧モデルと新モデルを比較する。前日比較は参考値（開催条件差に注意）。

**現状:** 独立の集計・検査関数とテストを追加。正式買い目への入力は未接続、実データ取得・合法性の確認・校正・前向き比較は未了。既存の正式モデルと過去記録は不変。
