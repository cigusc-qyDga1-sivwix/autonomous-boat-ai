# 選手着順適性試験 v0.2：1着候補を保持

更新日：2026-11-02（JST）。正式モデルへの昇格ではなく、前向き試験の構造修正。

## 問題

v0.1は1着の相対スコア自体を変更しないが、全120通りを並べ直した後に上位N点を選ぶため、メインモデルが保持した1着候補を落とす。2・3着適性の試験が、頭候補の選び直しと混在していた。

main `308006db6e51dec3ceaca8d2875b89f9372a3c9f` の保存台帳から、2026-10-31と11-01の公式確認済み316Rを同じ固定版で再照合した。返還等の要確認8Rは除外した。すべてWATCHの仮想成績であり、正式BUYの成績ではない。

| 指標 | メイン | v0.1試験 |
| --- | ---: | ---: |
| 的中 | 127/316 | 131/316 |
| 仮想回収率 | 74.26% | 78.84% |
| 1着候補抜け | 43 | 93 |
| 2着組合せ抜け | 71 | 37 |
| 1・2着一致の3着抜け | 75 | 55 |

払戻増加だけでは採用しない。差額723,000円に対し、10/31鳴門2Rの試験だけの払戻983,600円が大きい。係数の有効性や安定した優位性は未確認。

## 修正

- オプトインで `racer-role-suitability-shadow-v0.2-head-preserved` を生成する。
- 各1着候補について、メインの点数と金額の分布を完全に維持し、その頭に対応する2・3着だけを再選定する。別の頭へ枠や資金を移さない。
- 選手の適性係数、元の1着スコア、メイン買い目、合計仮想50,000円は変更しない。
- 自動生成側は2026-11-02以降に新規固定する試験で有効にする。既存固定版を置換せず、旧v0.1も明示的に再現できる。
- 公式結果照合は版ごとの集計と1着抜け・3着抜けを追加する。混在時は `mixed_versions` を立て、`by_model_version` を優先する。

## 検証と限界

- Nodeの回帰テストで、6通りの頭を意図的に保持した対照を旧処理が削る現象と、新処理が頭別点数・配分を維持することを検証。
- Python/Nodeの連携と版別の公式照合、メイン買い目と固定版の不変を3テストで確認。
- 保存済み324Rの最終スナップショットで、旧v0.1の出力を完全一致で再現。台帳646版のSHAと内部の締切前時刻にも不整合なし。
- v0.2を過去の公式的中実績へ足さない。修正後の前向き成績は未取得であり、改善済みとは判定しない。
- 2日間の最終展示反映は8/324R。展示反映済み条件の評価は別集計し、展示前WATCHを正式BUYに読み替えない。

次は新規固定版の同一R比較で、頭候補抜けが対照と一致することを監査し、2着・3着抜け、的中率、払戻と高配当1件への依存を確認する。展示指標別アブレーションは別実験として維持する。
