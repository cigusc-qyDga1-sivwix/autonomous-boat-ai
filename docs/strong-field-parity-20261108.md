# BOAT LAB: 強豪混戦の1着リスク判定 v0.1

2026-11-08。「G1だから荒れる」とはせず、**選手実力の接近**と**1着シナリオの接近**を別々に扱う。

## 判定根拠（すべて発走前固定の未校正相対値）
- 選手能力の代理値：6艇の全国勝率。4艇以上が6.0以上、かつ強さ上位4艇の全国勝率差が1.5以内なら、ひとまず「実力者が多い」とみなす。
- 1着候補の接近：同じ正式予想の120組から得た各艇の1着相対シェアで、最上位艇が45%以下、かつ最上位と2位との差が10ポイント以下。
- **両方そろったときだけ** `STRONG_FIELD_CLOSE_HEADS`。強豪が多くても頭が明確なら `STRONG_FIELD_HEAD_SEPARATED`。頭が接近していても選手層が強豪中心でなければ `MODEL_CLOSE_HEADS_NOT_STRONG_FIELD`。
- 120組の相対評価は勝利確率ではない。勝率6.0、上位4艇の差1.5、45%、10ポイントは研究仮説であり、学習・検証済みの閾値ではない。
- 指標欠損、実進入の重複、相対シェアの欠損は `INSUFFICIENT_EVIDENCE` とし、強豪混戦と断定しない。
- SG/G1/PG1/G2/G3/一般のグレードはメタ情報。G1という名前だけで頭を均等化したり、24点まで購入する根拠にしない。

## 予想への反映範囲
- **正式v2.3の採用点数・買い目・仮想5万円・BUY/WATCH/SKIPを直接変更しない**。実力拮抗による1着リスク、強さ上位4艇の差、相対頭差を、発走前固定SHAの `strong_field_diagnostic` に同時保存する。
- 同じ上位の1着相対シェアを持つのに買い目に頭候補がない場合、警告を表示する。警告は無条件に買い目を増やす指示ではない。
- BOAT LABのレース詳細に混戦注意を出す。展示前の暫定予想は、展示・進入で変わり得る。
- 公式結果が確認できたときだけ、`forecast_audit.py` の `by_strong_field_formal` に混戦・非混戦別の実績を記録。11/8以前の未判定レースを混戦と後付けで分類しない。
- まず前向き100R以上で、1着捕捉率と回収率の傾向を会場・グレード・展示状況別に検証。差が再現しないなら検知規則を見直す。過去の実績に基づく係数の後付けは正式履歴に含めない。

## ロジックとテスト
- `scripts/strong_field_diagnostic.py` ：発走前入力のみで判定。
- `tests/test_strong_field_diagnostic.py` ：実力拮抗、明確な頭、G1でも非拮抗、欠損・進入の重複、結果漏洩、正式版SHA不変、監査分類。
- `node --check app/app.js` とGitHub Actionsで画面への警告反映を確認。
