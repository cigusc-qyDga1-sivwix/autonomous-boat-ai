# BOAT LAB 3種類の足・数値展示診断 v0.1（2026-11-10）

## 目的
各レースの**発走前に検証済み・6艇完備**の展示情報から、「出足系」「行き足」「伸び」の強弱傾向を3軸で表示する。これは**暫定的な相対順位の説明用診断**であり、実測した3種類のモーター性能、確率、正式予想の係数ではない。

## 計測情報の解釈
- 全国共通の通常展示タイム：基本的に直線の伸び足の参考。例外として**福岡は計測位置が違い**中間足・旋回の影響も受ける。
- オリジナル「直線」：BOATCASTでは一般に伸びの参考。ただし**浜名湖**公式の測定区間はバック前半の**出足・行き足**、**福岡**ではターン後の中間足・行き足。したがって同じ名称で全国一律の伸び補正にしてはいけない。
- オリジナル「まわり足」：ターン性能に関する情報。旋回操作も含むため、モーターの純粋な「出足」そのものとは断定しない。
- 「一周／桐生の半周ラップ」：総合・旋回が混ざる。桐生の半周を一周へ数値変換しない。
- 展示ST：発進タイミングの個人技と進入状態が混ざるため、単独の機力「行き足」として採点しない。今後の映像でスリット後の相対加速を別途数値化する。

## 診断方法と欠損ガード
- 正式に発走前固定された `ticket_status=formal` + `phase=exhibition` の6艇のみ表示。過去の正式予想を生成し直さない。
- 同一場・同一レースの6艇で測定項目ごとの**順位**を比較する。値の欠損・不正・1艇だけの欠損は、その指標の全艇を評価保留。何もない項目を補完しない。場間の絶対秒数を比較しない。
- **伸び**：標準場は展示タイムと直線タイム。浜名湖・福岡は通常展示タイムを参考（福岡は計測条件の違いで信頼度を下げる）。
- **行き足**：浜名湖・福岡のみ、計測区間が該当するオリジナル直線を暫定参考。それ以外は数値による独立診断を**判定保留**とし、映像確認が必要。
- **出足系**：まわり足と一周／半周の順位を参考。出足だけに分離できないため、信頼度は上限「低」。
- 同じ指標の6艇の順位から「上位傾向／中位・拮抗／下位傾向／指標不一致／判定保留」を決める。信頼度の高・低は**資料の被覆度**であって確率ではない。
- ヒートや水面の引き波、船の旋回操作、展示後のペラ調整、モーター使用開始節や整備履歴までは補正しない。

## 統合と安全性
- `app/three-leg-diagnostic.js`：**画面表示専用・read-only** の独立評価モジュール。現時点では正式買い目の入力として使わない。結果・オッズは使用しない。
- `app/four-factor.js`, `app/index.html`：個別レースに「3種類の足・展示数値診断（研究用）」を追加。
- **正式v2.3の採用点数・1着評価・買い目・配分・BUY/WATCH/SKIP・公式照合・保存SHA・収支は全て不変。**
- `app/tests/three-leg-diagnostic.test.js`：6艇欠損、各場測定区間、正式／暫定、結果混入禁止、元スナップショット不変、UI表示を検証。

## 次のステップ
実映像・選手コメントから出足や行き足のラベルが検証できれば、現在の「参考」表示をモデル評価できる。導入効果を正式モデルへ反映するには、同一入力の前向き凍結と、最低100R程度の独立結果照合が必要。
