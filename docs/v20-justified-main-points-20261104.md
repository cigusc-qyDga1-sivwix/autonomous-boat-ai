# BOAT LAB v2.0 — 根拠の薄い120点拡張を正式メインから撤回（2026-11-04）

## 意思決定
「120通りを全評価する」ことと「120点を選んで仮想配分する」ことを切り離す。旧v1.8〜v1.9の **エントロピーが高いほど買い目を際限なく増やす仕様は、新しい正式予想では不採用** とする。

## 新正式予想の採否基準
- 全120組は**内部の着順比較・1〜3着評価専用**。メインの購入候補には全通りを出さない。
- **展示進入6艇、展示STと展示タイムの発走前固定がない**場合は原則最大8点。増加分は仮説上の先頭・2着ペアで説明でき、相対モデル評価がトップの62%以上の場合のみ。
- **展示情報が検証済み**の場合に限り、同条件の仮説上の1・2着ペアについて最大12点まで検討。追加分は相対評価55%以上を要求。
- **展示検証済み、さらに当該レースより前の選手×コース戦法実績が検証でき、5つの展開仮説で複数の頭候補が成立する場合**に限り、最大24点まで検討。追加分は相対評価48%以上であること。
- 評価がほぼ横並び（上位30番目が最上位の96%以上）の場合、広げる理由にならないため **SKIP** とする。最上位4点は画面の研究用候補であり、正式推奨・BUYではない。
- 採択点ごとに `interaction_primary.point_policy.ticket_reasons` で評価根拠の区分と該当展開仮説を保存。
- 場内の風などが実測できても、それだけでは2・3着候補を増やす因果的な根拠としない。12点超には過去の選手×コース戦法実績の検証を必須とする。
- この閾値は **確率や回収率を学習して導いたものではなく、増点の暴走を防ぐ暫定的なリスク制限**。24点は「24点買うべき」という意味ではない。
- 許可のない外部サイト収集、レース結果の遡及利用、映像がないのに実際の牽制を確認したと主張することは禁止。
- 新メインは`four-factor-v2.0-justified-points-primary-untrained`。2026-11-04 21:10 JST以降に作成された、締切まで安全余裕があるレースにだけ適用。過去v1.8/v1.9の予想、SHA、結果・収支は変更しない。
- 仮想資金は5万円で、採用した数点に1000円単位で配分する。実購入はしない。BUYの自動付与は引き続き禁止。江戸川除外は従来どおり。

## 制限と次の課題
- 「展開仮説の上位3組」は物理的な進路を観測した証拠ではない。相対評価だけでは十分な根拠にならないため、展示や履歴と同時に確認する。
- オッズ未取得・未校正のため、点数増加が回収率に有利とは言えない。将来のレースを発走前に固定したうえで、2着・3着抜けや回収率を継続監査する。
- 保存済みの最大120点履歴を読み込む互換処理は維持するが、**新正式メインが120点買い目を発行する経路は撤回**。
- 旧v1.8/v1.9の可変点数は履歴照合専用に残す。大量に買い目を増やした過去モデルの予想を新方式で上書きしない。
