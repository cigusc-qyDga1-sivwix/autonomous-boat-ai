# BOAT LAB v1.4 — 全国24場の分析と23場別戦法の前向き予想試験

**作成・試験開始：2026-10-27 JST。** 24場をデータ登録・分類。以前の指定を尊重し、**江戸川のみ新しい場別戦法倍率の対象外**。残り23場で発走前観測からの「外攻め頭・追走2着・内側残存3着」を**小幅・条件付き**で評価する。誇張のない予想改善評価を優先。

## 出典と解釈

1. BOAT RACEオフィシャル「[レース場ごとのコース別勝率](https://www.boatrace.jp/owpc/pc/extra/enjoy/guide/level2/l2_01_07_01.html)」では、住之江・大村のイン優勢、戸田・平和島・びわこのまくり傾向、桐生の風・福岡の1Mうねり等の場差を解説。
2. 「[勝ち艇ラボ・場別決まり手一覧](https://kachitei-lab.com/article/v_venue_decision)」に掲載の各場全レースの**逃げ・まくり・差し・まくり差し**割合を参照。掲載文では集計窓が「2016〜2025」と「〜2026年5月」で一部食い違っている。したがって**第三者の旧い記述統計**として扱い、特定期間・完全性を保証しない。割合は決まり手別の**その場の全勝者に占める割合**であり、当日の選手・コース条件付き勝率ではない。
3. 現場面の仮説・水質・潮の影響注意点・1コース参考値は既存の [24場プロフィール](../app/data/venue-profiles.json) と [`scripts/venue_profiles.py`](../scripts/venue_profiles.py)。参考1コース率の集計期間も曖昧なため係数を校正済みとはしない。
4. 追加の実進入別レース統計は既存の唐津・びわこ・福岡のみ（`app/tactical-1m.js`）。残る20場に公式6コース2・3着の条件付き頻度が存在すると装わない。
5. 風向きの有利・不利、潮の流向・水位、当日の映像で確認していない動きは**決め打ちしない**。場別の天候参考値・場内実測は元からある入力だけを使う。

## v1.4ロジック — 固定枠番フォーメーションからの脱却

- **既存v1.3を土台にする。** 選手60 / モーター25 / 展示10 / 気象5の未校正4要素、実進入6艇の脚力、合法展示ST、発走前の平均ST、引き波・攻め/追走・頭カバレッジを継承。
- **場別の1着戦法**：2コース差し／3・4コースまくり＋まくり差し／5・6コースまくり差し＋まくりを、各場の「過去の戦法構成の相対差」と組み合わせる。ここでのコース×戦法混合比は**検証用仮説**。実在する場別コース戦法割合ではない。
- **加点の条件**：場別プロフィール正当性、江戸川以外、選手間の**事前平均STまたは合法展示STの差が0.012秒以上**、十分な観測信頼度、相対脚力・ターン適性が揃う場合だけ。最大約±4.5%の倍率補正。見えていない差に先入観だけの加点はしない。
- **2着追走**：3〜5コースが攻め頭になる事前根拠と、外側の隣コース艇に追走可能な選手・機力があるときだけ、`P(隣コース2着 | 攻撃コース頭)`を小幅補正。
- **2着内残り／3着残存**：攻撃艇が勝っても1コース艇が残る条件を評価。`P(1コース2着 | 外頭)`と`P(1コース3着 | 外頭,外追走2着)`を別に計算。**場別実績の2・3着条件付き頻度は未取得**につき、この補正係数は統計的な学習値ではなく試験仮説。
- **強イン場にも例外を残す**：既存の1コース強弱補正と、新しい条件付き外頭・追走・内残存評価を同時に使う。1コースを無条件に固定したり、強まくり場でインを無条件に消したりしない。
- 旧v1.3と同様、**4〜12点・1レース仮想50,000円**。場別補正は点数拡大用ではない。実投票や外部通知はしない。
- **正式なSHAの不変性**：v1.4は`2026-10-27 18:30 JST`以降の生成にのみ適用可能（実際にコード統合されて稼働した後に生成されるものだけ）。既存の発走前固定予想を更新せず、締切前であれば別SHAの新バージョンを追記。締切後のレースを再予想しない。
- **旧版同条件シャドー**：v1.4 `venue_tactics_ab`に同一データ・同一`frozen_at_utc`の「場別補正OFF」と**v1.3**の両比較買い目を記録。差はモデル差であり、過去の的中結果を見て割り振らない。
- **江戸川**：v1.3のまま。研究一覧には観測情報を残すが、v1.4の新しい場別補正は採用しない。

## 進化と評価条件

1. **事前固定の新規レースだけ**で、v1.4 vs v1.3 vs 場別OFFを同じ場・R・時点で比較。
2. 場別（1場単位）で、頭捕捉／1・2着一致／3着抜け／3連単的中／仮想回収率／点数・欠損・ST有効数を集計。小数レースでの「場別成功」を断定しない。
3. 風向・潮位の真の場内観測、場別かつ実進入別の**各艇の1着/2着/3着実測頻度**、追走・内残存の映像ラベルを徐々に蓄積し、過去期間だけで係数を学習し、未来期間を丸ごと保留して予測の較正を検証する。
4. 今回の23場の補正係数は**仮説・未学習・未校正**。v1.4の導入だけでは的中率・回収率が改善したとは断定しない。将来のA/Bで改善が認められなければ場ごとに補正を縮小・停止する。
