# BOAT LAB 場別・展示タイム1項目除外試験 v0.2（2026-11-10）

## 何を検証するか
公式に計測された展示タイム、一周、桐生の半周ラップ、まわり足、直線の各指標について、
「6艇の同一レース・同じ発走前時刻・同じ仮想資金50,000円」で
**場別モーター×展示シャドーの全指標版**と、**1指標だけ除外した版**を同時に生成する。
比較対象は**研究用シャドー同士**であり、正式v2.3そのものの寄与率・投資助言とは混同しない。

## 実装
- `app/venue-motor-exhibition.js`: `venue_metric_ablation_key` に指定された当該場で測定される1項目だけ場別シャドー評価から除外。正式4要素と元入力には触れない。桐生は半周、一周とは混同しない。
- `scripts/main_four_factor_bridge.js`: 全指標版を固定する同じモデル処理内で、6艇完備の各指標をひとつずつ除外した仮想買い目を生成。独立 `metric_ablations[]` に発走前の `frozen_at_utc`、指標名、点数一致、変更有無、仮想配分を保存。個別の試験エラーは正式予想を止めない。
- `app/four-factor.js`: レース詳細に各指標の除外可否・点数一致・試験買い目／配分変更を表示。いずれも正式ではない。
- `scripts/forecast_audit.py`: 公式BOATRACE払戻で確認済みで、同一固定SHA、発走前固定、全指標版と除外版が共に仮想50,000円かつ**点数一致**のペアだけをレース・場・項目別に比較する。1着捕捉・2/3着抜け・3連単的中・仮想回収率を記録する。キャンセル・未確認・SHA不一致・締切後の試験は集計しない。

## 重要な制約
- **正式v2.3の予想・BUY/WATCH/SKIP・保存SHA・既存成績・実投票は変更しない。**
- 現在の場別倍率は事前登録の仮説であり、効果は未校正。改善を断定しない。
- 正式v2.3全体の展示の寄与をこの試験からは推定できない（除外するのは場別シャドー追加項のみ）。
- 6艇完備の該当指標が無ければ試験を作らない。欠損の重みを他項目へ再配分しない。
- 点数不一致のレースは同一点数評価対象から除外。日次でサンプル数と除外理由を記録する。
- 継続目標は**各指標で前向きに共通100R以上**、さらに場別で十分な標本。レース結果を見た後で同じ日の係数を合わせ直さない。正式採用には別途判断・PRが必要。

## 検証手順
`python -m pytest -q tests/test_venue_metric_ablation_audit.py`
`node app/tests/venue-metric-ablation.test.js`
`python scripts/forecast_audit.py --input app/data/live/latest.json --out /tmp/venue-ablation-daily-smoke.json`
