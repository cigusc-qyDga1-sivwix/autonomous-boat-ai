# BOAT LAB: 場別オリジナル展示の測定仕様と各レース評価（2026-11-10）

## 結論と区分
- **事実:** 公式 BOATCAST は展示タイム=主に伸び、一周=総合、まわり足=旋回、直線=伸びの参考と説明。ただし水面・測定区間が異なるため、全国一律の絶対秒数比較をしない。
- **事実:** BoatraceCSV の元データ仕様は、桐生「半周ラップ・まわり足・直線」、住之江・尼崎・徳山「一周・まわり足」、その他の開催23場「一周・まわり足・直線」主体。江戸川はオリジナル展示未配信。
- **観察:** 2026-10-28〜11-09の公開 per-source CSVで各場のラベル構成を確認。出走していない場や開催のない日は、その日のデータから断定しない。
- **仮説:** 場ごとに行き足・旋回・直線を重視する度合いが変わる。これは `app/venue-motor-exhibition.js` の23場 FOCUS にすでに試験設定されていたが、係数の予測性能は**未校正**。

## 実装：予想レースごとの確認
1. 同日・同場・同R・6艇の実進入/ST/通常展示タイムが一致し、オリジナル展示の測定SHAと初回取得時刻が締切前安全期限に適合した場合のみ使用する。過去の時刻を逆算しない。
2. 桐生は半周ラップ `half_lap_time` を独立の数値として保管する。一周 `lap_time` へ秒数変換しない。場別シャドーの go/turn にのみ組み込み、正式v2.3係数は変えない。
3. 住之江・尼崎・徳山の直線タイムは「元々測定されない」と判定し、`missing_expected_metrics` に入れない。江戸川は追加場別補正から除外する。
4. 展示タイム・一周/半周・まわり足・直線の各項目は**6艇完備時のみ有効**。欠測の係数を他項目へ再配分せず中立とし、同一レース内の6艇比較に限定する。
5. モーター2連対率との方向一致（双方良い/双方悪い）のみ最大およそ±3.5%の追加試験加減を、go/turn/straight別に反映。5m/s以上の近隣風予報は追加補正を縮小。風向・潮流不明時は物理的な向かい/追い風の優劣を推測しない。
6. 各レースに `venue_motor_exhibition_shadow`、`metric_scheme`、`expected_metrics`、`metric_coverage`、`missing_expected_metrics`、`not_measured_by_venue` と試験買い目/正式対照買い目を記録。アプリは項目別状態を表示する。

## 安全境界
**正式v2.3のモデル係数・BUY/WATCH/SKIP・買い目・既存固定SHA・正式仮想収支は変更しない。**
予測精度改善の証明とはみなさない。前向き100R以上の同一入力・同一点数比較（指標別除外試験を含む）、各場の適格標本、公式結果検証と改善が確定してから正式係数昇格を別判断。桐生の半周ラップは他場の一周と比較しない。
