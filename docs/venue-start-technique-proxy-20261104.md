# 23場別 ST×決まり手の攻防候補分析（2026-11-04）

ユーザー提案を場別に拡張。結果CSVの実際の進入コース、STと1着決まり手から、**まくり・まくり差しで勝ったレース**に限って、勝者と内側艇のST差を分類する。

- 23場（江戸川03除外）ごとに「外艇先行」「ST接近」「明確なST優位なし」「ST欠測/F」を集計
- 1着艇の実進入コース、決まり手、内側の比較対象コース別にも件数を保持
- 全場の過去レースを使った平均へ、仮の重み40件で平滑化。各場の有効比較30件未満は資料不足と明記
- 当該レース当日以降の結果は学習入力から拒否。場番号・レース識別子・データSHA・6艇進入を検証
- **勝ったまくりレースの中での割合**であり「まくりを試みた全レースの成功率」ではない
- 一つのレースで複数の内艇と比較するため、比較件数は「実際の牽制回数」ではない
- 江戸川は研究統計から除外。23場の既存水面プロフィールは名称照合のためだけに使用し、風潮の追加補正や場別有利艇係数は発明しない
- 無断スクレイピングなし。データ入力は権限のある過去レース行から

実行例:
```bash
python scripts/venue_start_technique_proxy.py --input /path/to/licensed_historical_rows.json --before-date 2026-11-04 --out /tmp/venue_st_tactics_20261104.json
python -m pytest -q tests/test_venue_start_technique_proxy.py
```

入力JSON: `[{"event_date":"2026-11-03","source_sha256":"<64 hex>","row":{"レースコード":"202611032101",...}}]`（この他に実進入6艇、ST、1着艇、決まり手を含む）。

**実装と未実装の区別:** 本PRは場別の過去結果集計・切り分け・単体テストの実装。自動取得、23場の実績数字の検証、戦法の場別補正を正式買い目へ自動投入する作業は別工程。履歴収集がない現状では推測で数字を埋めない。

将来の前向き比較では、場別分析なし／ありを同一レースの発走前固定入力で比較し、的中・仮想回収率・3着抜け・外枠入着を評価する。水面・天候による交絡を場別条件に含め、当日までの結果から同日朝の過去時点を過小評価しないよう時点管理する。
