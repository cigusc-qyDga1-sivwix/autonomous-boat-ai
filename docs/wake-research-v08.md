# BOAT LAB 引き波研究 v0.8 — 全レース初期ON、影響は展開別

**区分:** 研究用アニメーション・事後集計のみ。正式予想 v0.7 の固定買い目・SHA・収支を変更しない。

## 公式解説で確認できること

- 児島公式 https://www.kojimaboat.jp/beginner_guide.html : 1周2マーク以降の後続艇は先行艇が作る引き波で不利になるが、2・3着争いと逆転がある。
- 徳山公式 https://www.boatrace-tokuyama.jp/modules/beginner/ : 先行艇が有利で後続艇は引き波の影響を受ける。
- 住之江公式 https://guide.boatrace-suminoe.jp/jp/basic_race.html : 1周2マーク以降の引き波による不利を説明。
- Oregon Marine Board https://www.oregon.gov/osmb/boater-info/pages/wake.aspx : 一般ボートの引き波は速度、船型、姿勢、重量、水深などで異なる。競艇艇の実減速量や確率を示す研究ではない。
- 児島公式の風・潮資料 https://www.kojimaboat.jp/pdf/br16book.pdf : 水面の荒れ・潮・風による旋回難易度は異なる。自然波とうねりと、先行艇が残す引き波を混同しない。

## 予想・アニメの条件付き研究対象

1. 3〜6コースの攻めによる1Mの内側艇への引き波リスク。内側艇が必ず失速したとは判定しない。1・2・3着へ残る別展開を維持する。
2. 1コース逃げも含む全戦法における、2M以降の2・3着追走艇への引き波リスク。
3. 近接コースのスタート差・保存済み回り足など、引き波回避を考える際の状況要因。ただし実際の接触位置は測定していない。
4. ④⑤⑥の攻め・追走と2着浮上。外枠を無条件優遇/減点しない。
5. 展開アニメの引き波ONは初期設定。ONでもリスクがないと判定した艇には一律の減速を仮定しない。ユーザーがOFFにした後の買い目切替ではOFFを維持する。

## 計測・検証の制約

現在は艇の本番航跡、引き波位置、接触時刻、艇速の前後実測、1M通過順位が欠損。アニメ内の引き波や進行量は**説明用模式図**で、実測減速・本当の着順・確率は示さない。

過去の決まり手と着順を事後的に集計する research_wake_hypotheses.py は、接触の因果関係を学習するものではない。別ファイル wake-study-latest.json に集計し、正式発走前予想に取り込まない。固定履歴は不変。

次の本格的な改善には、動画の個別確認から 1M攻め位置・波の通過位置・回避成否・2M順位・後続艇の足をラベル付けし、別モデルの発走前固定検証100R以上で判定する必要がある。
