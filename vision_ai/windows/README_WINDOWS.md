# BOAT VISION AI / Windows試験版

Windows 10/11 x64、インストール済みのMicrosoft Edgeを使用します。
Pythonのインストール、Docker、管理者権限は不要です。ZIPをすべて展開してから実行してください。
Windows実機での初回再生・取得は未確認です。この配布は取得成功を保証するものではありません。

## 初回の操作

1. `CHECK_RUNTIME.cmd` を開き、READYが表示されるか確認します。
2. `config.json` の `event_date` を公式画面で展示リプレイが公開されている日付（例: `2026-10-28`）、`races` を対象R（例: `[1]`）にします。初期値 `today` は日本時間の当日です。未公開・非開催日は取得できません。
3. `START_CAPTURE.cmd` を開きます。Edgeが開き、三国の公式画面で展示と日付/Rを選択します。処理中は開いたEdgeを操作しないでください。
4. `outbox` に結果JSONができます。失敗も記録されます。終了窓はキーを押すまで残ります。

手動でレースを選んだりSTARTを入力したりする必要はありません。
`START_WATCH.cmd` は同じ対象を最大3回、180秒間隔で試します。成功済みRは同じ実行中は繰り返しません。
常駐・日次実行ではありません。Ctrl+Cで停止できます。視聴拒否・対象不一致ではすぐ停止します。

## 結果の読み方

- `RENDERED_CANDIDATES_UNVERIFIED`: 動く表示画素の検査と候補追跡の処理が終了。6艇識別の証明ではありません。
- `stages.six_candidates_simultaneous`: 同じ場面で6色の候補が4フレーム以上同時に支持されたか。
- `candidate_boat_tracks`: 未確認の色・動き候補数。`confirmed_boat_tracks` は常に0。
- `RENDERED_FRAMES_STATIC_OR_BLACK`: 黒画面・静止画。成功扱いしません。
- `RACE_NOT_AVAILABLE`: 指定日/Rの展示リンクがありません。公開範囲の日付を確認します。
- `VIEWING_DENIED`: 視聴拒否。繰り返しや回避は行いません。
- `PLAYBACK_CLOCK_NOT_ADVANCING` / `PLAYBACK_INTERRUPTED`: 通常再生が成立していません。
- `BROWSER_RUNTIME_FAILED`: Edge起動・画面操作などの失敗。取得成功を記録しません。
- `FRAME_VALIDATION_FAILED`: 時刻の停止・不安定、画像サイズの変化などで解析を拒否。

`report_sha256` は改変検出用で、実映像・精度を独立に証明する署名ではありません。
`rendered_frame_sequence_sha256` は画面上のサンプル列のハッシュで、元動画のハッシュではありません。
動きは画素単位の研究値です。速度はブラウザ時計の中央間隔による近似値で、m/sなどの実速度ではありません。

## データと分離

ユーザー申告の三国・個人分析許可の範囲に限定した初期版です。許可の根拠を `permission_reference` に残します。
ブラウザが通常再生した映像要素の画像をRAMで最大24MB処理し、動画や画像をアプリからファイルへ保存・送信しません。
ブラウザは一時プロファイルを使い、終了時に閉じます。保存量のカウンタは本アプリの出力のみを対象とします。
メディアURLの抽出、署名トークン取得、アクセス制御の回避はしません。

数値JSONはこのフォルダの `outbox` にのみ保存します。**クラウドへの自動送信は未接続**です。
クラウド連携前にWindows実機で再生・動く画素・候補数を順に確認するための版です。
画像による独立正解付け、精度検証、スタート・旋回・出口の区間特定は未完了です。
正式買い目・研究用シャドーとも反映不可。BOAT LAB本体、予測、結果台帳を読み書きしません。

## ファイル

`runtime` はPython公式のアプリ専用実行環境とPyPIの依存パッケージです。
`BUILD_MANIFEST.json` に取得元・バージョン・SHA-256を記録しています。個別ライセンスは同梱しています。
Edgeの追加ダウンロードは行いません。インストール済みEdgeが必要です。
削除するときは起動窓を終了し、この展開フォルダを削除してください。
